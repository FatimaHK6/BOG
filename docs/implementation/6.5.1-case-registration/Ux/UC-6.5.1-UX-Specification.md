## 8. Validation Messages

### 8.1 Error Messages (Arabic)
| Code | Message |
|------|---------|
| ERR008 | الممثّل موجود مسبقاً للمدعي |
| ERR011 | المدّعي موجود مسبقاً بنفس رقم الهوية |
| ERR012 | رقم هوية الممثّل نفس رقم هوية المدّعي |
| BR04 | يجب أن يكون الملف بصيغة PDF فقط |
| BR04 | حجم الملف يتجاوز الحد الأقصى (4 ميجابايت) |
| BC07 | فقط المدعي من نوع 'فرد' يمكنه أن يكون مقدم الطلب |

### 8.2 Success Messages
| Action | Message |
|--------|---------|
| Add Plaintiff | تم إضافة المدعي بنجاح |
| Update Plaintiff | تم تحديث بيانات المدعي بنجاح |
| Delete Plaintiff | تم حذف المدعي بنجاح |
| Add Representative | تم إضافة الممثل بنجاح |
| Add Attachment | تم رفع المرفق بنجاح |
| Set Applicant | تم تعيين مقدم الطلب بنجاح |

## 9. Responsive Behavior

### 9.1 Desktop (> 1200px)
- Full side navigation visible
- 2-column forms
- Full table with all columns

### 9.2 Tablet (768px - 1200px)
- Collapsible side navigation
- 1-column forms
- Horizontal scrolling tables

### 9.3 Mobile (< 768px)
- Bottom navigation
- Card-based list views
- Full-width forms
