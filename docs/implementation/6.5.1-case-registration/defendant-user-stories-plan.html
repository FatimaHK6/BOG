1- فرد بيانات شخصية بيانات مكان الإقامة بيانات جهة العمل
2- شركة مسجلة بيانات السجل التجاري بيانات العنوان الوطني للشركة -
3- جهة حكومية بيانات الجهة الحكومية - -
4- شركة غير مسجلة بيانات الشركة - -
5- صاحب مؤسسة بيانات شخصية بيانات صاحب المؤسسة بيانات المؤسسة
6- جمعية/مؤسسة أهلية بيانات جمعية / مؤسسة أهلية عنوان الجمعية / المؤسسة الأهلية -
7- وقف بيانات الوقف بيانات العنوان الوطني للوقف -
محتوى التبويبات:
  • بيانات شخصية (فرد):
    • نوع الهوية (هوية وطنية / مقيم فقط - بدون جواز سفر)، رقم الهوية، الاسم الأول، اسم الأب، اسم الجد، اسم الفخذ، اسم العائلة، تاريخ الميلاد، الجنسية، الجنس، رقم الجوال
    • حقول مخفية: تاريخ إصدار الهوية، تاريخ انتهاء الهوية
    • الحقول الإجبارية: الاسم الأول، اسم الأب (إجباري فقط إذا نوع الهوية = هوية وطنية)، اسم العائلة، الجنس، الجنسية، رقم الجوال
    • الحقول الاختيارية: نوع الهوية، رقم الهوية، اسم الجد، اسم الفخذ، تاريخ الميلاد
  • بيانات مكان الإقامة (فرد): المنطقة (إجباري)، المدينة (إجباري)، الحي (اختياري)، الشارع (اختياري)، رقم المبنى (اختياري)، رقم الوحدة (اختياري)، الرمز البريدي (اختياري)، الرمز الافتراضي (اختياري)
  • بيانات جهة العمل: حالة العمل (اختياري)، جهة العمل (إجباري شرطي)، المهنة (إجباري شرطي)
    • شرط الإظهار: يظهر حقول جهة العمل والمهنة فقط إذا كانت حالة العمل = حكومي أو خاص
    • شرط الإخفاء: يُخفى حقول جهة العمل والمهنة إذا كانت حالة العمل = بدون عمل أو غير محددة
    • الحقول الإجبارية الشرطية: جهة العمل والمهنة إجبارية عند اختيار حالة العمل = حكومي (1) أو خاص (2)
  • عنوان العمل (فرد - خاص فقط): المنطقة (إجباري)، المدينة (إجباري)، الحي (إجباري)، الشارع (إجباري)، رقم المبنى (إجباري)، رقم الوحدة (إجباري)، الرمز البريدي (إجباري)، الرمز الإضافي (إجباري)
    • شرط الإظهار: يظهر نموذج العنوان الوطني للعمل فقط إذا كانت حالة العمل = خاص
    • شرط الإخفاء: يُخفى نموذج العنوان الوطني للعمل إذا كانت حالة العمل = حكومي أو بدون عمل
    • الحقول الإجبارية: جميع حقول عنوان العمل إجبارية عند إظهار النموذج
  • بيانات الشركة: رقم السجل التجاري (20 حرف)، اسم الشركة (200 حرف)، الدولة (اختيار من قاعدة البيانات)، المدينة (100 حرف)، وصف تقريبي (1000 حرف)
  • بيانات السجل التجاري: رقم السجل، تاريخ البداية، تاريخ النهاية
  • بيانات الجهة الحكومية: اختيار الجهة من القائمة، المقر، بيان إضافي
  • بيانات شخصية (صاحب مؤسسة): نوع الهوية (هوية وطنية / مقيم فقط - بدون جواز سفر)، رقم الهوية، الاسم الأول، اسم الأب، اسم الجد، اسم الفخذ، اسم العائلة، تاريخ الميلاد، الجنسية، الجنس، رقم الجوال
  • بيانات صاحب المؤسسة: بيانات المالك الشخصية
  • بيانات المؤسسة: اسم المؤسسة، السجل التجاري، العنوان
  • بيانات الجمعية: اسم الجمعية، عنوان الجمعية
  • بيانات الترخيص: رقم الترخيص، مصدر الترخيص، تاريخ الترخيص
  • بيانات الوقف: اسم الوقف، رقم صك المحكمة، تاريخ الصك، مصدر الصك، نظارة الوقف

7 قواعد العمل

7.1 قواعد الإظهار والإخفاء

الرمز القاعدة الشرط التطبيق
BC01 بيانات جهة العمل (جهة العمل، المهنة) تظهر إذا حالة العمل = حكومي أو خاص
تُخفى إذا حالة العمل = بدون عمل		 Frontend + Backend
BC02 العنوان الوطني للعمل (صاحب مؤسسة فقط) يظهر فقط إذا حالة العمل = خاص
يُخفى إذا حالة العمل = حكومي أو بدون عمل		 Frontend + Backend
BC03 التكامل مع أبشر اختياري وليس إجباري (على عكس المدعي) Backend Service
BC04 اسم الأب إجباري فقط إذا نوع الهوية = هوية وطنية
اختياري إذا نوع الهوية = هوية مقيم		 Frontend + Backend
BC05 الجنسية إذا نوع الهوية = هوية وطنية: "سعودي" (للقراءة فقط)
إذا نوع الهوية = مقيم/جواز: اختيار من القائمة (بدون سعودي)		 Frontend + Backend
BC06 اسم الجهة (وقف) يظهر فقط إذا نظارة الوقف = حكومية
يُخفى إذا نظارة الوقف = أهلية		 Frontend + Backend
BC07 حقول الأسماء (صاحب مؤسسة) للقراءة فقط إذا تم الجلب من أبشر (هوية وطنية/مقيم)
قابلة للتعديل إذا نوع الهوية = جواز سفر		 Frontend

  const identityTypeId = this.form.get('identityTypeId')?.value;

  if (!identityNumber || !identityTypeId) {
    this.snackBar.open('يرجى إدخال رقم الهوية ونوع الهوية', 'إغلاق', { duration: 3000 });
    return;
  }

  // بيانات وهمية (استبدل بـ API حقيقي لاحقاً)
  const absherData = this.getMockAbsherData(identityNumber, identityTypeId);

  // ملء الحقول
  this.form.patchValue({
    firstName: absherData.firstName,
    fatherName: absherData.fatherName,
    grandfatherName: absherData.grandfatherName,
    tribeName: absherData.tribeName,
    familyName: absherData.familyName
  });

  // قفل الحقول
  this.isAbsherLocked = true;
  this.snackBar.open('تم جلب البيانات بنجاح', 'إغلاق', { duration: 3000 });
}

11.6 معالجة وضع التعديل

عند تحميل مدعى عليه موجود في وضع التعديل:

  • إذا تم جلب البيانات مسبقاً من أبشر (تخزين علامة)، إبقاء الحقول مقفلة
  • حالياً (وهمي)، السماح بالتعديل دائماً في وضع التعديل حتى التكامل الحقيقي

11.7 التحقق

  1. فتح نموذج الفرد: http://localhost:4200/case-registration/defendants/add/individual?requestId=1
  2. إدخال رقم الهوية (مثال: 1234567890)
  3. اختيار نوع الهوية
  4. النقر على "جلب البيانات من أبشر"
  5. التحقق من:
    • ملء الحقول ببيانات وهمية
    • تصبح الحقول للقراءة فقط (رمادية)
    • نوع الهوية ورقم الهوية تبقى قابلة للتعديل
  6. تكرار الاختبار لنموذج صاحب المؤسسة
