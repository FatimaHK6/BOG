1 plaintiff-form.component.html تعديل صغير تغيير زر "إضافة ممثل" ليستخدم [matMenuTriggerFor] بدلاً من (click)="onAddRepresentative()" مباشرة.

2 plaintiff-form.component.ts تعديل صغير تعديل onAddRepresentative() ليقبل representativeTypeId كمعامل.
تمرير النوع المختار إلى Dialog عبر dialogData.
إضافة متغير لأنواع الممثلين المفلترة (يمكن استخدام ALLOWED_REPRESENTATIVE_TYPES الموجود).
3 representative-dialog.component.html تعديل صغير تحويل حقل نوع الممثل من <mat-select> قابل للتعديل إلى عرض نص فقط (readonly display).
مثل طريقة عرض نوع المدعي في plaintiff-form.component.html.
4 representative-dialog.component.ts تعديل صغير قراءة representativeTypeId من data المُمررة وتعيينها مباشرة في النموذج.
إزالة أو تعديل onRepresentativeTypeChange() لأن النوع لن يتغير.
عرض اسم النوع المختار.
ملاحظة مهمة: لا يوجد ملف جديد مطلوب. التغيير يتم بالكامل في 3-4 ملفات موجودة (HTML + TS).
لا يوجد أي تغيير في Backend أو API أو قاعدة البيانات.

4. خطة التنفيذ التفصيلية

  1. تحميل أنواع الممثلين المفلترة في plaintiff-form
    plaintiff-form.component.ts

    التغيير:
    • إضافة متغير filteredRepresentativeTypes لتخزين الأنواع المتاحة حسب نوع المدعي المختار
    • عند تغيير نوع المدعي أو عند تحميل النموذج، فلترة الأنواع باستخدام ALLOWED_REPRESENTATIVE_TYPES[plaintiffTypeId]
    • استيراد ALLOWED_REPRESENTATIVE_TYPES من representative.model.ts (مستخدم بالفعل)

    كود مقترح: 
    // في plaintiff-form.component.ts
filteredRepresentativeTypes: RepresentativeType[] = [];

private loadRepresentativeTypes(): void {
  this.lookupService.getRepresentativeTypes().subscribe(types => {
    const allowedIds = ALLOWED_REPRESENTATIVE_TYPES[this.selectedPlaintiffType] || [];
    this.filteredRepresentativeTypes = types.filter(t => allowedIds.includes(t.id));
  });
}
  2. تحويل زر "إضافة ممثل" إلى قائمة Menu
    plaintiff-form.component.html

    الوضع الحالي: 
    <button mat-raised-button color="primary" (click)="onAddRepresentative()">
  إضافة ممثل
</button>
    المطلوب: 
    <button mat-raised-button color="primary" [matMenuTriggerFor]="repTypeMenu">
  إضافة ممثل
</button>
<mat-menu #repTypeMenu="matMenu">
  <button mat-menu-item
          *ngFor="let type of filteredRepresentativeTypes"
          (click)="onAddRepresentative(type.id)">
    {{ type.nameAr }}
  </button>
</mat-menu>
  3. تعديل onAddRepresentative() لتمرير النوع
    plaintiff-form.component.ts

    الوضع الحالي: 
    onAddRepresentative(): void {
  const dialogData: RepresentativeDialogData = {
    plaintiffId: this.plaintiffId || 0,
    plaintiffTypeId: this.selectedPlaintiffType,
    ...
  };
}
    المطلوب: 
    onAddRepresentative(representativeTypeId: number): void {
  const dialogData: RepresentativeDialogData = {
    plaintiffId: this.plaintiffId || 0,
    plaintiffTypeId: this.selectedPlaintiffType,
    representativeTypeId: representativeTypeId,  // NEW
    ...
  };
}
  4. تعديل RepresentativeDialogData interface
    representative.model.ts أو representative-dialog.component.ts

    التغيير:
    • إضافة representativeTypeId إلى interface RepresentativeDialogData
    export interface RepresentativeDialogData {
  plaintiffId: number;
  plaintiffTypeId: number;
  representativeTypeId: number;  // NEW - pre-selected type
  plaintiffIdentityNumber?: string;
  existingRepresentatives?: any[];
}
  5. تعديل representative-dialog: عرض النوع كنص ثابت
    representative-dialog.component.html + representative-dialog.component.ts

    الوضع الحالي (HTML): 
    <mat-form-field appearance="outline" class="full-width">
  <mat-label>نوع الممثل</mat-label>
  <mat-select formControlName="representativeTypeId" required>
    <mat-option *ngFor="let type of representativeTypes" [value]="type.id">
      {{ type.nameAr }}
    </mat-option>
  </mat-select>
</mat-form-field>
    المطلوب (HTML): 
    <div class="representative-type-display">
  <span class="type-label">نوع الممثل:</span>
  <span class="type-value">{{ selectedRepresentativeTypeName }}</span>
</div>
    التغيير (TS): 
    ngOnInit(): void {
  // تعيين النوع مباشرة من data
  this.repForm.patchValue({
    representativeTypeId: this.data.representativeTypeId
  });
  // عرض اسم النوع
  this.selectedRepresentativeTypeName = this.representativeTypes
    .find(t => t.id === this.data.representativeTypeId)?.nameAr || '';
  // تطبيق المنطق المشروط للنوع مباشرة
  this.onRepresentativeTypeChange(this.data.representativeTypeId);
}

5. ما لا يتغير (بدون تأثير)

المكون التأثير السبب
Backend API لا تغيير لا يتأثر - نفس البيانات تُرسل بنفس الشكل
Validators / التحقق لا تغيير نفس المنطق الحالي يعمل بعد تعيين النوع مسبقاً
قاعدة البيانات لا تغيير لا يوجد تغيير في البنية أو البيانات
حفظ / تعديل البيانات لا تغيير نفس الـ submit logic يبقى كما هو
فلترة الأنواع حسب المدعي لا تغيير نفس قاموس ALLOWED_REPRESENTATIVE_TYPES يُستخدم
المرفقات لا تغيير منطق المرفقات مستقل عن طريقة اختيار النوع
تعديل ممثل موجود لا تغيير عند التعديل يُفتح Dialog مع بيانات محملة مسبقاً (النوع ثابت)

6. المخاطر والملاحظات

المخاطرة الاحتمال التأثير الحل
بعض أنواع المدعي لها ممثل واحد فقط (مثل Type 5 = وكيل فقط) منخفض القائمة تعرض خياراً واحداً فقط إذا كان نوع واحد متاح، يمكن فتح Dialog مباشرة بدون menu، أو إبقاء القائمة كما هي
تعديل ممثل موجود - يجب أن يبقى النوع ثابتاً منخفض لا تأثير عند التعديل، Dialog يفتح مباشرة بالنوع المحفوظ (لا يمر بالـ menu)
الحقول المشروطة حسب نوع الممثل (مثل حقول المحامي) منخفض لا تأثير نفس المنطق الحالي onRepresentativeTypeChange() يعمل عند التهيئة

7. أنواع الممثلين المتاحة حسب نوع المدعي (مرجع)

نوع المدعي الأنواع المتاحة عدد الخيارات
1 - فرد وكيل، أمين تفليسة، ولي، وصي 4
2 - فرد بدون هوية جميع الأنواع (9) 9
3 - صاحب مؤسسة وكيل، أمين تفليسة، ولي 3
4 - شركة مسجلة وكيل، مصفي، أمين تفليسة، حارس قضائي، ممثل نظامي 5
5 - شركة غير مسجلة وكيل فقط 1
6 - جهة حكومية وكيل، ممثل جهة حكومية 2
7 - جمعية/مؤسسة أهلية وكيل فقط 1
8 - وقف وكيل، ناظر 2
ملاحظة: للأنواع 5 و 7 (خيار واحد فقط)، يمكن اختيار أحد الأساليب:
  1. عرض القائمة بخيار واحد (بسيط ومتسق)
  2. فتح Dialog مباشرة بالنوع الوحيد المتاح (UX أفضل)

8. الخلاصة النهائية

التقييم: منخفض التكلفة

درجة التعقيد: منخفض
عدد الملفات: 3-4 ملفات تعديل، 0 ملفات جديدة
تغييرات Backend: لا يوجد
نوع التغيير: UI/UX فقط - تغيير تدفق الاختيار

الملخص: التغيير بسيط ومباشر. يتطلب فقط نقل نقطة اختيار نوع الممثل من داخل Dialog إلى قائمة Menu قبل فتح Dialog. جميع منطق الأعمال والتحقق والحفظ يبقى كما هو بدون أي تعديل. الممثل يبقى في Dialog كما هو حالياً.
