# 3. إدارة المدعين

## 3.1 المدعين (6.5.1.1.1)

**الوصف:** عرض وإدارة نماذج بيانات المدعين مع عمليات متعددة.

**الشروط الاستباقية:**
- المستخدم مسجل دخول
- المستخدم معين على قسم/دائرة
- المحكمة تطابق الدعوى

### المسارات البديلة

| الرمز | الوصف |
|-------|-------|
| ALT01 | إضافة مدّعي |
| ALT02 | تفاصيل مدّعي |
| ALT03 | تعديل مدّعي |
| ALT04 | العنوان المختار |
| ALT05 | المرفقات |
| ALT06 | إضافة ممثّل |
| ALT09 | تحديد كمقدّم طلب |
| ALT10 | حذف مدّعي |

### قواعد العمل

| الرمز | القاعدة |
|-------|---------|
| BC01 | الخيارات (إضافة، حذف، تحديد كمقدّم طلب) تظهر في حالات: لا يوجد حالة / مسوّدة / استكمال النواقص |
| BC02 | خيار تعديل يظهر في حالات: لا يوجد حالة / مسوّدة |
| BC03 | خيار العنوان المختار يظهر إذا اختلفت مدينة المدّعي عن مدينة المحكمة |
| BC07 | خيار تحديد كمقدّم طلب يظهر فقط إذا كان نوع المدّعي فرد |

---

## 3.2 إضافة مدعي (6.5.1.1.2)

**الوصف:** إضافة مدعي جديد على طلب قيد الدعوى.

**الشروط الاستباقية:**
- الطّلب مقدّم من داخل المحكمة
- حالة الطلب: لا يوجد حالة / مسوّدة / استكمال النواقص

### المسار الرئيسي

1. اختيار نوع المدعّي
2. عرض نموذج البيانات المقابل
3. تعبئة نموذج بيانات المدعّي
4. حفظ

### قواعد العمل

| الرمز | القاعدة |
|-------|---------|
| BC01 | عرض نموذج البيانات المقابل لنوع المدّعي المختار |
| BC02 | التكامل مع أبشر للمواطن/المقيم |

### الاستثناءات

| الرمز | الوصف |
|-------|-------|
| ERR011 | مدّعي موجود مسبقاً بنفس رقم الهوية ونوع المدّعي |
| ERR014 | خطأ في الاتصال بأبشر |
| ERR016 | لم يتم استرجاع بيانات من أبشر |

**الوصف:** إضافة ممثل جديد للمدّعي.

**الشروط الاستباقية:**
- حالة الطلب: لا يوجد حالة / مسوّدة / استكمال النواقص

### المسار الرئيسي

1. تعبئة البيانات الشخصية للممثّل
2. اختيار نوع التمثيل
3. تعبئة نموذج بيانات التمثيل
4. حفظ

### الاستثناءات

| الرمز | الوصف |
|-------|-------|
| ERR008 | ممثّل موجود مسبقاً للمدّعي |
| ERR012 | رقم هوية الممثّل نفس رقم هوية المدّعي |

# 5. إدارة الطلب

## 5.1 معلومات إضافية (6.5.1.1.15)

**الوصف:** إضافة معلومات إضافية حسب نوع النزاع.

### أنواع المعلومات الإضافية

**1. إلغاء قرار إداري:**
- رقم القرار، تاريخ القرار، طريقة الإبلاغ، الجهة المصدرة

**2. حقوق خدمة/تقاعدية:**
- رقم التظلم، تاريخ التظلم، الجهة المتظلم لديها، نتيجة البت

**3. نزاع علامة تجارية:**
- رقم طلب تسجيل العلامة، تاريخ الطلب

- المرفقات
- الموضوع والبيّنات والطلبات
