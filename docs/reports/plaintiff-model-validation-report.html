❌ مشكلة حرجة: حقل جهة العمل غير مُحقق للنوع 3

الوصف: حقل جهة العمل (Employer) مطلوب في SRS 6.3.8 لنوع "صاحب مؤسسة" ولكن FluentValidation لا يفرض هذا الشرط.

الملف: src/Backend/BOG.DTO/Plaintiff/PlaintiffCreateDTOValidator.cs

السطور: 96-137

التأثير: يمكن حفظ سجلات صاحب المؤسسة بدون معلومات جهة العمل.

الكود الحالي:
When(x => x.PlaintiffTypeId == TypeBusinessOwner, () => { // ... other validations ... RuleFor(x => x.Profession) .NotEmpty().WithMessage("المهنة مطلوبة"); // Employer is NOT validated! });
الكود المطلوب:
RuleFor(x => x.Employer) .NotEmpty().WithMessage("جهة العمل مطلوبة");

⚠️ مشكلة رئيسية: طول حقل عنوان الشركة غير المسجلة غير موثق

الوصف: حقل UnregisteredCompanyAddress له حد أقصى 500 حرف في DTO ولكن SRS لا يحدد هذا القيد.

الملف: src/Backend/BOG.DTO/Plaintiff/PlaintiffCreateDTO.cs

السطر: 206

التوصية: توثيق هذا القرار أو التحقق مع محللي الأعمال.

ℹ️ ملاحظة: DataSourceId غير موجود في جداول حقول SRS

الوصف: الكيان و DTO يتضمنان DataSourceId (لتتبع تكامل أبشر) والذي غير موثق صراحة في جداول حقول SRS، لكنه مذكور في قواعد العمل (BR08).

التأثير: لا يوجد - هذا حقل داعم لمنطق الأعمال.

ℹ️ ملاحظة: رسائل التحقق بالعربية فقط

الوصف: جميع رسائل التحقق بالعربية وهو صحيح لمجال العمل، لكن لا توجد ترجمة إنجليزية لفرق الدعم الدولية.

التأثير: منخفض - مقبول لنظام عربي فقط.
