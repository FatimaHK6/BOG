قواعد حقل الجنسية:

  • إذا كان نوع الهوية = هوية وطنية: الجنسية تكون "سعودي" (عرض فقط - غير قابل للتعديل)
  • إذا كان نوع الهوية = هوية مقيم: الجنسية تكون اختيار من قائمة الجنسيات (باستثناء "سعودي")

قواعد العمل الشرطية:

  • BC01: يتم إظهار حقل "جهة العمل" فقط إذا كانت حالة العمل = حكومي أو خاص. يتم إخفاؤه إذا كانت حالة العمل = بدون عمل.
  • BC02: يتم إظهار "عنوان العمل" فقط إذا كانت حالة العمل = خاص. يتم إخفاؤه إذا كانت حالة العمل = حكومي أو بدون عمل.

قواعد التكامل مع أبشر:

عند تفعيل التكامل مع أبشر وإدخال رقم الهوية (مواطن/مقيم)، تصبح الحقول التالية غير قابلة للتعديل:

  • نوع الهوية، رقم الهوية، تاريخ الميلاد
  • الاسم الأول، اسم الأب، اسم الجد، اسم الفخذ، اسم العائلة
  • تاريخ إصدار الهوية، تاريخ انتهاء الهوية

المسار الرئيسي:

  1. تعبئة البيانات الشخصية للممثّل
  2. اختيار نوع التمثيل
  3. تعبئة نموذج بيانات التمثيل
  4. حفظ
