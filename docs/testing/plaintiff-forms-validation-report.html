3. المشاكل الرئيسية - Major Issues

🟠 MAJ-01: الحقول المطلوبة غير مُطبقة

الحقول المطلوبة في SRS منفذة كـ nullable بدون [Required] attribute

🟠 MAJ-02: تحقق رقم السجل التجاري خاطئ

الحد الأقصى 20 حرف بدلاً من 10 أرقام للشركات المسجلة (SRS 6.3.3)

🟠 MAJ-03: تحققات التاريخ مفقودة

عدم التحقق من التواريخ المستقبلية ومقارنات التواريخ

🟠 MAJ-04: حقل الجنس يفتقر لتحقق القيم

يجب أن يقبل فقط "ذكر" أو "أنثى"

🟠 MAJ-05: تحقق تنسيق رقم الهوية مفقود

10 أرقام للهوية الوطنية/الإقامة vs 20 حرف لجواز السفر

🟠 MAJ-06: نوع نظارة الوقف يفتقر للتحقق

يجب أن يقبل فقط "خاصة" أو "حكومية"

🟠 MAJ-07: التحقق الشرطي مفقود

اسم الجهة مطلوب عندما تكون النظارة "حكومية"

🟠 MAJ-08: تحقق النص العربي مفقود

SRS يحدد نص عربي فقط لحقول معينة

6. التوصيات - Recommendations

التوصية الرئيسية: استخدام FluentValidation

يُوصى باستخدام FluentValidation للتعامل مع قواعد التحقق الشرطية المعقدة بدلاً من الاعتماد على Data Annotations فقط.

public class PlaintiffCreateDTOValidator : AbstractValidator<PlaintiffCreateDTO> { public PlaintiffCreateDTOValidator() { // Type 1: Individual - requires personal data When(x => x.PlaintiffTypeId == 1, () => { RuleFor(x => x.IdentityTypeId).NotNull() .WithMessage("نوع الهوية مطلوب للأفراد"); RuleFor(x => x.FirstName).NotEmpty() .WithMessage("الاسم الأول مطلوب"); }); // Type 8: Waqf - conditional WaqfAgencyName When(x => x.PlaintiffTypeId == 8 && x.WaqfOversightType == "حكومية", () => { RuleFor(x => x.WaqfAgencyName).NotEmpty() .WithMessage("اسم الجهة مطلوب عندما تكون النظارة حكومية"); }); } }
