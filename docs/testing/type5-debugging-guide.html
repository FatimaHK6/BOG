فحص طلب الإنشاء (CREATE) - عند إضافة مدعي جديد

1. أنشئ مدعي جديد من نوع "شركة غير مسجلة"

2. املأ جميع الحقول (رقم السجل، اسم الشركة، الدولة، المدينة، الوصف)

3. اضغط حفظ وراقب تبويب Network

ابحث عن الطلب:

POST /api/case-requests/{requestId}/plaintiffs

افحص Request Body (Payload):

{ "plaintiffTypeId": 5, "commercialRegNumber": "1234567890", "companyName": "اسم الشركة", // === الحقول المطلوب التحقق منها === "countryId": 1, // <-- هل موجود وليس null؟ "unregisteredCompanyCity": "الرياض", // <-- هل موجود؟ "description": "وصف الشركة" // <-- هل موجود؟ }
إذا كانت القيم null أو غير موجودة:

المشكلة في Frontend - الحقول لا ترسل للـ Backend

إذا كانت القيم موجودة وصحيحة:

انتقل للخطوة 3 لفحص الاستجابة

3

فحص استجابة الإنشاء (CREATE Response)

في نفس الطلب، اضغط على تبويب Response أو Preview

افحص Response Body:

{ "id": 123, "plaintiffTypeId": 5, "commercialRegNumber": "1234567890", "companyName": "اسم الشركة", // === هل رجعت هذه القيم من الـ Backend؟ === "countryId": 1, // <-- ما هي القيمة؟ "unregisteredCompanyCity": "الرياض", // <-- هل موجودة؟ "description": "وصف الشركة" // <-- هل موجودة؟ }
إذا كانت القيم null في الاستجابة:

المشكلة في Backend - البيانات لا تُحفظ في قاعدة البيانات

4

فحص طلب التحميل (GET) - عند تعديل مدعي موجود

1. افتح قائمة المدعين

2. اضغط على زر التعديل لمدعي من نوع "شركة غير مسجلة"

3. راقب تبويب Network

ابحث عن الطلب:

GET /api/plaintiffs/{plaintiffId}

افحص Response Body:

{ "id": 123, "plaintiffTypeId": 5, // === تحقق من هذه القيم === "countryId": ???, // <-- ما هي القيمة الفعلية؟ "unregisteredCompanyCity": "???", // <-- ما هي القيمة؟ "description": "???" // <-- ما هي القيمة؟ }
انتبه لقيمة countryId:

إذا كانت القيمة مثلاً countryId: 100 ولكن قائمة الدول في الـ Frontend تحتوي على IDs من 1-7 فقط، فالقائمة المنسدلة ستظهر فارغة!

5

فحص Console للتحقق من الـ Patching

افتح تبويب Console في DevTools وابحث عن هذه الرسائل:

=== PATCHING FORM WITH PLAINTIFF === Plaintiff data: {id: 123, plaintiffTypeId: 5, countryId: 1, ...} plaintiffTypeId from data: 5 === TYPE CHANGED === New typeId: 5 typeof: number isPatching: true // <-- يجب أن يكون true
إذا كان isPatching: false:

الـ Flag لا يعمل بشكل صحيح ويتم مسح الحقول

إذا كان isPatching: true:

الـ Reset يتم تخطيه بشكل صحيح

ملخص الحقول المطلوب فحصها

Field (Arabic) Form Control JSON Property (Request) JSON Property (Response)
رقم السجل التجاري commercialRegNumber commercialRegNumber commercialRegNumber
اسم الشركة unregisteredCompanyName companyName companyName
الدولة unregisteredCountryId countryId countryId
المدينة unregisteredCity unregisteredCompanyCity unregisteredCompanyCity
وصف تقريبي unregisteredDescription description description

قائمة التحقق

عند الإنشاء (CREATE)

  • ☐ Request يحتوي على countryId
  • ☐ Request يحتوي على unregisteredCompanyCity
  • ☐ Request يحتوي على description
  • ☐ Response يرجع نفس القيم

عند التحميل (GET)

  • ☐ Response يحتوي على countryId (قيمة رقمية)
  • ☐ Response يحتوي على unregisteredCompanyCity
  • ☐ Response يحتوي على description
  • ☐ countryId يطابق ID في قائمة الدول (1-7)

في Console

  • ☐ isPatching = true عند التعديل
  • ☐ Plaintiff data يحتوي على القيم
  • ☐ لا توجد أخطاء JavaScript

بعد الفحص، أخبرني:

1. هل البيانات موجودة في POST Request؟

2. هل البيانات ترجع في GET Response؟

3. ما هي قيمة countryId في الاستجابة؟

4. هل isPatching = true في Console؟
